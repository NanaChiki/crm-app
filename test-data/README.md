# テストデータ

CSVインポート機能のテスト用サンプルデータです。

## ファイル一覧

### 1. sample-customers-standard.csv（標準ヘッダー）
- **件数**: 20件
- **ヘッダー**: `会社名,担当者,電話番号,メールアドレス,住所,備考`
- **用途**: 最も一般的なヘッダー名でのテスト

### 2. sample-customers-jobcan-style.csv（ジョブカン風）
- **件数**: 20件
- **ヘッダー**: `顧客名,連絡先担当,TEL,email,所在地,メモ`
- **用途**: ジョブカンからエクスポートした場合を想定

### 3. sample-customers-english.csv（英語ヘッダー）
- **件数**: 10件
- **ヘッダー**: `company,contact,phone,mail,address,notes`
- **用途**: 英語ヘッダー名でのマッピングテスト

### 4. sample-customers-duplicates.csv（重複テスト）
- **件数**: 5件（うち3件が重複）
- **用途**: 重複チェック機能のテスト
- **期待動作**:
  - 新規2件が登録される
  - 重複3件がスキップされる
  - エラーメッセージに重複理由が表示される

### 5. sample-customers-errors.csv（エラーケース）
- **件数**: 5件（うち2件がエラー）
- **用途**: バリデーションのテスト
- **期待動作**:
  - 会社名が空の行がスキップされる
  - エラーメッセージが表示される

## テスト手順

### 1. 標準ヘッダーのテスト
```bash
npm run dev
```
1. アプリ起動
2. 設定 → データ連携タブ
3. 「顧客データをCSVからインポート」クリック
4. `sample-customers-standard.csv` 選択
5. 結果確認: 「20件の顧客データをインポートしました」

### 2. ジョブカン風ヘッダーのテスト
1. `sample-customers-jobcan-style.csv` インポート
2. 結果確認: 「20件の顧客データをインポートしました」
3. ヘッダー名が異なっても正しくマッピングされることを確認

### 3. 重複チェックのテスト
1. `sample-customers-duplicates.csv` インポート
2. 結果確認: 「2件の顧客データをインポートしました（3件スキップ）」
3. エラーメッセージに重複理由が表示されることを確認

### 4. エラーケースのテスト
1. `sample-customers-errors.csv` インポート
2. 結果確認: 会社名が空の行がスキップされる
3. エラーメッセージが分かりやすいことを確認

## 期待される結果
