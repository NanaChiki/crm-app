# 叔父さん向けインストールガイド（Zoom画面共有用）

## 事前準備（山本側）

### 1. Google Driveにアップロード
1. https://drive.google.com にアクセス
2. `MaintenanceMate-Setup-1.1.0.exe` をアップロード
3. ファイルを右クリック → 「共有」
4. 「リンクを知っている全員」に変更
5. リンクをコピー

### 2. 叔父さんにメール送信

**件名**: メンテメイト v1.1.0 インストール用リンク

**本文テンプレート**:
```
〇〇叔父さん

お疲れ様です。山本です。

メンテメイトの新しいバージョン（v1.1.0）が完成しました。
ジョブカンから顧客データをインポートできる機能を追加しています。

下記のリンクからダウンロードできます：
[Google Driveリンクをここに貼る]

インストールは少し複雑なので、Zoomで画面を見ながら一緒に作業しましょう。
以下の日程でご都合いかがでしょうか？

・12月〇日（〇）〇時〜
・12月〇日（〇）〇時〜

所要時間は20〜30分程度です。

よろしくお願いいたします。

山本
```

## Zoom画面共有時の作業手順（30分想定）

### Phase 1: 旧バージョンアンインストール（5分）

**画面共有を開始してもらう**

**指示内容**:

1. 「Windowsキーを押してください」
2. 「メンテメイト と入力してください」
3. 「右クリックしてください」
4. 「アンインストール をクリックしてください」
5. 「はい をクリックしてください」
6. 「完了したら教えてください」

**トラブル対応**:
- 見つからない場合: 「設定 → アプリ → インストールされているアプリ」から探す

---

### Phase 2: 新バージョンダウンロード（5分）

**指示内容**:

1. 「メールを開いてください」
2. 「私が送ったメールのリンクをクリックしてください」
3. 「右上の ダウンロード ボタンをクリックしてください」
4. 「ダウンロードが完了したら教えてください」

**トラブル対応**:
- リンクが開けない: ブラウザでGoogle Driveリンクを直接入力

---

### Phase 3: インストール実行（10分）

**指示内容**:

1. 「画面下のダウンロードフォルダをクリックしてください」
2. 「MaintenanceMate-Setup-1.1.0 をダブルクリックしてください」
3. **重要: Windows SmartScreen警告が表示される**
   - 青い画面が表示されます
   - 「詳細情報 をクリックしてください」（More infoと英語の場合もあり）
   - 「実行 をクリックしてください」（Run anywayと英語の場合もあり）
4. 「次へ をクリックし続けてください」
5. 「インストールが完了したら教えてください」

**トラブル対応**:
- SmartScreen警告で「詳細情報」が見つからない: 画面の左下を探す
- インストールが進まない: Windowsの更新が必要な可能性

---

### Phase 4: 初回起動確認（5分）

**指示内容**:

1. 「デスクトップのメンテメイトアイコンをダブルクリックしてください」
2. 「ダッシュボードが表示されたら成功です」
3. 「総顧客数が 0 と表示されていますか？」

**確認項目**:
- ✅ アプリが起動する
- ✅ ダッシュボードが表示される
- ✅ エラーメッセージが表示されない

---

### Phase 5: ジョブカンCSV確認（5分）

**指示内容**:

1. 「ジョブカンを開いてください」
2. 「顧客一覧ページを開いてください」
3. 「エクスポートボタンや、CSVダウンロードボタンがありますか？」

**3パターンの対応**:

#### ケースA: CSVエクスポートボタンがある
→ 「そのボタンをクリックして、CSVファイルをダウンロードしてください」
→ 「ダウンロードしたファイルを私にメールで送ってください」
→ 次回Zoom: 私がインポートテストして問題なければ、叔父さんのPCでインポート実行

#### ケースB: エクスポート機能が見当たらない
→ 「ジョブカンのサポートに問い合わせる必要があります」
→ または、「手動でデータを移行する方法を検討します」

#### ケースC: CSVはあるが有料プランのみ
→ 「プラン変更が必要か、代替案を検討します」

## 代替シナリオ: 事前にCSVファイルだけ入手

### もしZoom前にCSVファイルを入手できる場合

1. **叔父さんに依頼**:
   - 「ジョブカンから顧客データをCSVでエクスポートしてください」
   - 「そのファイルをメールで送ってください」

2. **私（山本）がMacでテスト**:
   - CSVファイルをダウンロード
   - `npm run dev` で開発環境起動
   - CSVインポート実行
   - エラーがないか確認
   - ヘッダーマッピングが必要か確認

3. **Zoom時の作業が簡略化**:
   - インポートテストは完了済み
   - 叔父さんのPCで本番インポート実行のみ
   - トラブルシューティング不要

## 想定トラブルと対処法

### トラブル1: SmartScreen警告が怖くて進めない

**対処法**:
- 「これは正常な警告です。新しいアプリは必ず表示されます」
- 「私が作ったアプリなので安全です」
- 「詳細情報をクリックして、実行をクリックしてください」

### トラブル2: ダウンロードファイルが見つからない

**対処法**:
- 「エクスプローラーを開いてください」
- 「左側のダウンロードをクリックしてください」
- 「MaintenanceMate-Setup-1.1.0.exe を探してください」

### トラブル3: インストール中にエラー

**対処法**:
- エラーメッセージをスクリーンショット
- 私が原因を調査
- 最悪の場合、後日再実施

### トラブル4: アプリが起動しない

**対処法**:
- 「Ctrl + Shift + I で開発者ツールを開いてください」
- コンソールのエラーを確認
- 私がリアルタイムでトラブルシューティング
